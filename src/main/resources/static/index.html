The root user credentials require the password set in the root environment variable on the server.

How to set the environment variable:

Windows (CMD): 
set root=your_password
.\mvnw.cmd spring-boot:run
Windows (PowerShell): 
$env:root="your_password"
.\mvnw.cmd spring-boot:run
Linux / macOS: 
export root="your_password"
./mvnw spring-boot:run

Note: If not set, the root password defaults to an empty string.
